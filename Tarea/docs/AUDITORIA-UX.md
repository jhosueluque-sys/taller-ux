# Auditoría UX/UI: Lista de tareas

## 1. Objetivo

Evaluar la interfaz original de la lista de tareas e implementar mejoras que faciliten su uso, comprensión y accesibilidad.

## 2. Problemas identificados en la versión original

- El diseño tenía una apariencia básica y poca separación visual entre sus elementos.
- Los botones de completar y eliminar utilizaban símbolos poco descriptivos.
- El formulario permitía agregar tareas vacías.
- No existía una opción para recuperar una tarea eliminada.
- Los mensajes de respuesta y los estados de los filtros podían ser más claros.

## 3. Mejoras implementadas

- Se creó una interfaz oscura y minimalista con una mejor distribución de los elementos.
- Se mejoró el contraste y el tamaño de los controles.
- Se incorporó validación para impedir el registro de tareas vacías.
- Se habilitó el registro de tareas mediante la tecla Enter.
- Se añadieron contadores para las tareas y sus filtros.
- Se implementó una opción para deshacer la última eliminación.
- Se incorporaron etiquetas accesibles y estados de interacción visibles.

Las capturas se guardarán en esta carpeta, con nombres descriptivos.

## 5. Conclusión

El trabajo permitió identificar problemas de presentación y funcionamiento en la versión inicial de la lista de tareas. Las mejoras se realizaron por etapas para mantener un registro de los cambios mediante Git. La nueva interfaz ofrece controles más claros, validaciones y una opción para recuperar tareas eliminadas. Las pruebas finales permitirán comprobar si estas mejoras funcionan correctamente y si la aplicación resulta más sencilla de utilizar.
